# pop-ghost!(demo)
ポップゴースト！ (Pop Ghost!) 👻✨ 〜 ゆるかわ出現放置ゲーム (Webデモ版) 〜  お部屋の中に次々と現れる、ゆる〜くて可愛いおばけたち。 指やマウスで画面をスーッとなぞって、まとめてドバッと吸い込もう！ 集めた「おばけ玉」でお部屋を拡張したり、おばけキャッチャーを動かして図鑑コンプリートを目指そう！  
🎮 ゲームの特徴 - 指でなぞるだけの爽快アクション: 湧いてきたおばけを気持ちよく一気にバキューム！ - 全56種類のおばけたち: - 個性豊かな通常おばけ（30種）- 曜日・月ごとにしか現れない限定おばけ（19種） - 毎日遊んで迎える通算ログイン記念おばけ（7種）
